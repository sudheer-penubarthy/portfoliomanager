## What You Need

A simple way to move ALL remaining .md and .txt files to docs/ at once!

---

## 🚀 THE FASTEST WAY (30 seconds)

### Copy-Paste This Command in PowerShell

1. **Open PowerShell** in your project root folder:
   - Shift+Right-Click → "Open PowerShell window here"

2. **Paste this command:**
```powershell
Get-ChildItem -File -Include *.md,*.txt | Where-Object {$_.Name -ne "README.md"} | ForEach-Object { Move-Item -Path $_.FullName -Destination "docs\$($_.Name)" -Force }
```

3. **Press Enter**

✅ **DONE!** All .md and .txt files moved to docs/ in seconds!

---

## 📋 Alternative: Windows File Explorer (1 minute)

1. Open folder: `C:\development\fincal_projects\portfoliomanager\`
2. Select all .md and .txt files (skip README.md)
3. Cut (Ctrl+X)
4. Open docs/ folder
5. Paste (Ctrl+V)
